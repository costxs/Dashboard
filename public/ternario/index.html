Diagrama Ternário LCPETRO

Tensoativo/cotensoativo no vértice superior, água à esquerda, óleo à direita. Frações em massa; classificação por marcador.

● local (navegador)

Cada linha de titulação parte de uma massa fixa de tensoativo/cotensoativo (C/T) mais a fase fixa (óleo ou água) dentro de um tubo pesado com o peixe. A cada adição, anote a massa total lida na balança; o titulante é a diferença para a massa inicial. Marque "transição" na adição em que o sistema mudou e escolha a nova classe; a classe vale até a próxima transição.

Pontos avulsos (composições diretas, em %). Os três valores são normalizados para 100 %.

Dados gerais do diagrama

Um JSON de diagrama vira uma nova aba neste projeto; um JSON com vários projetos substitui o conjunto. CSV de pontos: colunas serie,sc,agua,oleo,winsor,rotulo (percentuais), adicionado como pontos avulsos deste diagrama. Tudo fica guardado também neste navegador.
